产品定位：RMR 1:2.05 是一款**微型反射式红点瞄准镜**（红色反射式红点），LED 红点亮度可调，支持手动 9 档亮度与自动感光（ALS）两种模式，采用 2×SR516SW 氧化银纽扣电池供电，针对**长时间待机、低功耗、掉电不丢配置**做了专门设计。

## 2. 快速上手

1. **安装电池**：装入 2×SR516SW 纽扣电池（标称 3.1V，注意极性）。
2. **开机**：同时按住 **BT1 + BT2 两颗键 1.5 秒**。电压达标（> 约 2.2V）即亮灯，进入上次保存的模式（出厂为手动模式默认第 4 档亮度）。
   - 若在关机状态下**直接长按双键满 5 秒**：双闪提示后以**自动感光（ALS）模式**开机。
3. **调节亮度**：开机状态下——
   - **BT2（+）短按**：手动模式升一档；ALS 模式偏移 +30%（最高 +50%）。
   - **BT1（-）短按**：手动模式降一档；ALS 模式偏移 -30%（最低 -50%）。
4. **关机**：同时按住双键 **1.5 秒熄灯后松开**（未按满 5 秒）即确认关机，进入深睡省电。
5. **使用提示**：红点亮度在 ALS 模式下自动跟随环境光；长期无操作会自动调暗、关机以省电；低电量时 LED 会每 2 秒闪一下提示（见第 4、5 章）。

> 若开机无反应（灯不亮），请检查电池电压：电压低于约 2.2V 时保护机制会拒绝开机，属于正常保护行为（见 5.4 节）。

## 3. 完整操作手册

### 3.1 按键说明

两颗物理按键（低有效，硬件去抖）：

- **BT1（-）**：短按降亮度 / 偏移减
- **BT2（+）**：短按升亮度 / 偏移加
- **双键（BT1+BT2 同时）**：开关机、模式切换、进入 FLASH 模式

### 3.2 开机

| 操作 | 触发条件 | 结果 |
|---|---|---|
| 双键按住 1.5s | 关机态，电压达标（> lvp_ext+100mV ≈ 2.2V） | 开机，进入上次保存的模式（手动/ALS）与档位 |
| 双键按住 1.5s | FLASH 模式 | 测压开机（与关机态一致） |
| 双键直接按住满 5s | 关机态 | 双闪提示 + **以 ALS 模式开机**（电压达标；失败会再试一次） |
| 上电（冷启动） | 仅 POR/BOR/SHUTDOWN 退出等冷启动原因 | 自动开机（FEATURE_AUTO_POWER_ON）；调试复位/看门狗复位不自动开机 |

电压不达标时：LED 闪 100ms 提示，保持关机。

### 3.3 关机与深睡

| 操作 | 结果 |
|---|---|
| 运行中双键按住 1.5s | 立即熄灯进入“待关机”状态 |
| 熄灯后松开（未满 5s） | 确认关机 → 进入 STANDBY0 深睡（µA 级） |
| 熄灯后继续按住满 5s | 双闪提示 + **切换 ALS⇄手动并重新亮灯**（电压达标） |

> 关键点：**灭灯 ≠ 立即深睡**。必须“松开且未满 5s”才会真正进入深睡；一直按到 5s 则变成模式切换。这是刻意设计，防止误触关机后又唤醒。

### 3.4 亮度调节（运行中）

手动模式（MAN）：9 档亮度，映射 brt = {5, 20, 50, 150, 300, 450, 600, 800, 1000}，出厂默认第 4 档（300）。

| 操作 | 手动模式 | ALS 模式 |
|---|---|---|
| BT2 短按 | 亮度升一档（受电压安全上限约束，越限档仍可升但会标记 overshot） | 亮度偏移 +30%（+50% 封顶） |
| BT1 短按 | 亮度降一档（已越限时先回落到安全亮度） | 亮度偏移 -30%（-50% 封底） |

### 3.5 模式切换（ALS ⇄ 手动）

- 运行中：**双键按住 1.5s 熄灯 → 继续按满 5s** → 双闪提示，自动在 **ALS ⇄ 手动**之间切换并亮灯（电压达标）。
- 关机态：直接**双键长按满 5s** → 以 ALS 模式开机。
- ALS 传感器连续 3 次故障自恢复后锁定 ALS 时：当前在 ALS 仍可切回手动；手动试图切 ALS 会被拒绝（双闪提示），避免传感器永久损坏时反复闪烁。

### 3.6 FLASH 模式（烧录/调试模式）

| 操作 | 结果 |
|---|---|
| 关机态按住 BT1 0.8s（电压达标，冷启动后仅一次） | 进入 FLASH 模式：VCC_EN 拉高、NRST 恢复、SWD 可连接 |
| FLASH 模式中双键 1.5s | 测压开机，退出 FLASH 模式 |
| FLASH 模式 5 分钟无操作 | 自动复位 |

### 3.7 无操作自动调暗 / 关机

- **40 分钟**无任何按键操作 → 自动调暗到最低亮度（brt=5）。
- 调暗后再过 **10 分钟**仍无操作 → 自动关机。
- 任意按键事件立即恢复亮度并重新计时。

## 4. 指示灯（LED）状态速查

| 现象 | 含义 |
|---|---|
| 常亮（亮度按档位/ALS 曲线） | 正常运行 |
| 双键 1.5s 后熄灭 | 进入待关机，松开确认关机 |
| 熄灯后按住至 5s 时**双闪** | 模式切换提示（ALS⇄手动） |
| 开机失败时闪 100ms | 电压不达标，拒绝开机 |
| **每 2s 闪 50ms** + 亮度降到 1/4 | **低电量警示**（电压 < 2.3V，见 5.1） |
| **每 1.5s 周期闪（亮 600ms）** | **ALS 传感器故障**（连续 3 次读取失败，见 5.6） |

## 5. 机制介绍（用户视角）

### 5.1 低电量模式（LVP_CRIT）

- 触发：电池电压**连续 5 次采样 < 2300mV**。
- 表现：LED **每 2 秒闪 50ms** 提示低电量，同时亮度自动降为 1/4，优先保证还能继续使用一段时间。
- 恢复：电压回升到 2400mV 以上自动恢复正常模式。
- 作用：避免电压过低时 LED 突然熄灭或电流异常，让用户有足够时间更换电池。

### 5.2 严重低电量保护（LVP_EXT 关机）

- 触发：电压**连续 5 次采样 < 2100mV**。
- 动作：**立即关机**，并在关机前自动保存当前配置（档位/模式/偏移）。
- 目的：防止电池过放损坏电池寿命；配置不会丢，换电池后开机自动恢复。

### 5.3 断电保护（掉电保存）

- 触发：检测到**快速掉电**（单次原始电压 < 2000mV 即触发，不等待多次采样）。
- 动作：**瞬间断开 PWM**（LED 立即停止耗电，让电压回升稳定）→ **立即强制保存**配置到 Flash（NVM）→ 进入 SHUTDOWN（断电保护态）。DBG/DBGL 调试版不 SHUTDOWN，只保存配置以保持 SWD 可连。
- 时序保证：先断 PWM 再擦写 Flash，避免掉电瞬间 LED 继续拉电流导致电压塌陷、NVM 擦写中断丢配置。
- 关机才多次采样：缓慢掉电（< 2100mV 连续 5 次）走低电量关机路径；< 2000mV 说明电源已断，必须立即保存。
- 目的：**任何时刻拔电池/掉电，档位、模式、偏移都不会丢**——保存走“强制保存”路径，不依赖 30 秒后台定时保存。

### 5.4 开机测压门控

- 无论按键开机还是调试器开机，都先测电压，**必须 > lvp_ext + 100mV（约 2.2V）才允许启动**。
- 电压不足时 LED 闪 100ms 提示并保持关机。
- 目的：防止电池接近耗尽时开机造成 LED 亮度不足/闪烁的“假启动”体验。

### 5.5 自动关机（省电）

- 40 分钟无操作调暗 → 再 10 分钟无操作关机进深睡。
- 深睡（STANDBY0）：MCU 进入最低功耗状态，仅保留按键唤醒；任意按键按下立即唤醒。
- 唤醒后自动恢复亮度并重新计时。

### 5.6 ALS 自动感光与故障处理

- ALS 模式下，红点亮度跟随环境光自动调节：环境越亮红点越亮，越暗越暗（有最低亮度 30 保底，避免全黑时红点不可见）。
- 传感器连续 **3 次**读取失败 → 进入 ALS 故障态：LED **每 1.5s 周期闪烁**提示；**10 秒后自动恢复**并切回手动模式（配置落盘）。
- 连续 3 次“故障→自恢复”后**锁定 ALS**：拒绝从手动切回 ALS，防止传感器永久损坏时反复闪烁（当前在 ALS 仍可切回手动）。

### 5.7 配置记忆与掉电保存

- 所有设置（档位、模式、ALS 偏移、电压参数等）自动保存到 Flash（NVM，双扇区多槽位、写后校验、坏槽跳过）。
- 日常调节只标记“待保存”，后台 **30 秒**自动落盘（减少 Flash 磨损）；**关机、低电量关机、掉电**时强制立即保存。
- 恢复出厂：调试器执行“恢复出厂+保存”指令；烧录后可选首次上电清空存储区（出厂配置开关）。

## 6. 常见问题（FAQ）

**Q1：灯灭了，松手又亮了？**
A：双键 1.5s 熄灯后必须**松开且未按满 5s** 才会确认关机进深睡；如果一直按到 5s 会切换 ALS/手动模式并重新亮灯。这是设计行为，防止误触关机。想关机就“按 1.5s 灭灯 → 松手”。

**Q2：怎么切换自动感光（ALS）和手动模式？**
A：运行中双键按 1.5s 灭灯后**继续按满 5s**，双闪提示后即切换并亮灯。关机状态下直接长按双键满 5s 会以 ALS 模式开机。

**Q3：ALS 模式下亮度没变化/没效果？**
A：先确认当前是 ALS 模式（双键 5s 切换）；环境光变化需要几秒平滑过渡（防抖）；若传感器故障会闪烁提示并 10s 后自动切回手动（见 5.6）。

**Q4：灯每 2 秒闪一下？**
A：低电量警示：电压连续低于 2.3V，亮度同时降到 1/4。请尽快更换电池；电压回升后自动恢复。

**Q5：为什么按开机没反应？**
A：开机前会测电压，低于约 2.2V 拒绝开机并闪 100ms。请更换电池或用稳压电源供电。

**Q6：电压低的时候为什么升不了档？**
A：自适应档位限制在起作用：电压不足时亮度上限被压低（防止 LED 过流/电池过放），此时升档可能被标记越限但亮度不增。属正常保护。

**Q7：关机后配置会丢吗？**
A：不会。关机、低电量关机、掉电都会强制保存配置到 Flash；日常调节后台 30s 自动落盘。

**Q8：电池能用多久？**
A：取决于亮度档位。LED 最大电流 2.8mA、电池 12.5mAh×2：最高亮度档连续点亮约数小时；自动调暗/关机后深睡电流极低（µA 级），待机可达数月量级。实际以测量为准。

**Q9：OFF 态 SWD 连不上调试器？**
A：普通版关机后进 STANDBY0 深睡（SWD 断开），属于正常省电行为。需要关机态可连请用 DBG 变体，或在调试器中置位 FLAG_SWD_IN_OFF_STATE。

**Q10：如何进入烧录/调试模式（FLASH 模式）？**
A：关机状态下按住 BT1 0.8s（电压达标）进入 FLASH 模式，5 分钟无操作自动复位；也可以直接用调试器烧录（会自动处理）。

**Q11：怎么恢复出厂设置？**
A：用 RMRDebugger 调试器执行“恢复出厂+保存”（系统指令 5），档位/偏移/特性标志全部恢复出厂默认并立即保存。

**Q12：红点有轻微亮度波动/闪一下？**
A：属于电压补偿在起作用时的正常现象；如果规律性闪烁请对照第 4 章指示灯速查判断是否低电量或 ALS 故障。

| 上电自动开机（仅冷启动生效） | FEATURE_AUTO_POWER_ON / bit7 | 已支持 |
| ECO 动态降频 / WFI 睡眠 / 采样电源门控（省电变体） | POWER_SAVE_BUILD | 已支持（ECO_D / ECO_B） |
| 开机测压门控、掉电保存、恢复出厂、调试信箱/注入 | — | 已支持 |

> 结论：**自适应电压补偿已支持**，核心是“恒流模型”——LED 平均电流由 brt/1000 × I_max 决定，PWM 占空比按当前电压下的峰值电流实时反推；电压下降时峰值电流变小，占空比自动增大，从而维持亮度恒定。详见第 11 章。

## 8. 产品组成与硬件资料

RMR 1:2.05 主要组成部分：

- 主控：TI MSPM0C1104（Cortex-M0+，24MHz 总线时钟，1ms 硬件时基由 GPTIMER14 产生）
- 红点光源：APTD1608SECK-J4 红色 LED（Vf 约 2.2V，最大电流 2.8mA），PWM 恒流驱动
- 环境光传感器：TI OPT3001（I2C，软件模拟时序，GPIO 位操作）
- 供电：2×SR516SW 氧化银纽扣电池（标称 3.1V，12.5mAh/节，内阻约 25Ω/节）或 1.6–3.6V 可调稳压电源直连（120–635Ω 可调限流电阻）
- 操作：BT1 / BT2 两颗物理按键（低有效，8 次采样去抖）
- 调试/烧录：仅 SWD（XDS110 或 DAPLink），无 UART

编译产物：firmware/RMR/hex/（6 个 hex）；firmware/RMR.hex 为发布镜像。

## 10. 系统状态机

```
                    +------ 双键 1.5s（测压达标）------+
SYS_OFF <-----------+                                v
   ^                |                          SYS_RUN -> SYS_LVP_CRIT（连续 5 次 <2300mV）
   | 双键1.5s熄灯    |                                |  ^
   | (松开<5s进STANDBY0)  v                          |  | 电压回升+迟滞
   |             SYS_FLASH_MODE（单键BT1 0.8s进入，5min超时复位）|
   |                  |                              v  |
   +------------------+---- 双键 1.5s 测压开机 <------+--+
                                              ^
   SYS_ALS_ERR --10s 自恢复--> SYS_RUN（切回手动并落盘）
        ^
        +-- ALS 连续 3 次读取失败（闪烁提示，1.5s 周期）

   SYS_TEST_MODE（调试器授权进入）--> 正常退出 = SYS_FLASH_MODE；授权丢失 = 复位
```

- SYS_OFF：LED 全灭；默认版本若未置位“OFF 态 SWD”标志则进入 STANDBY0 深睡
- SYS_RUN：正常运行（手动/ALS 亮度控制）
- SYS_LVP_CRIT：低电压临界，LED 每 2s 闪 50ms 且亮度降为 1/4 警示
- SYS_FLASH_MODE：烧录/调试模式（VCC_EN 拉高、NRST 恢复、SWD 可连），5min 无操作自动复位
- SYS_ALS_ERR：ALS 故障，LED 以 1.5s 周期闪烁（亮 600ms），10s 后自恢复
- SYS_TEST_MODE：调试器授权后进入，支持注入与系统命令

## 11. 亮度控制与自适应电压补偿（核心算法）

### 11.1 亮度标度

- 逻辑亮度 brt：0-1000（1000 = 满亮）
- 物理 PWM 寄存器：0-2399（PWM_REG_MAX），CC=2399 表示占空比 0（灭）

### 11.2 恒流 PWM 补偿（battery_brt_to_pwm）

```text
目标平均电流   i_req = brt / 1000 x I_max            （I_max = 2.8mA 默认）
峰值电流       i_peak = (Vbatt - Vf) / R_total       （Vf = 2.2V）
占空比         duty  = i_req / i_peak（上限 100%）
PWM 装载值      CC = 2399 - duty x 2399 / 1000
```

电压下降 -> i_peak 变小 -> duty 自动上升 -> 亮度维持。这就是自适应电压补偿：不靠查表，完全由恒流模型实时反推。

### 11.3 动态内阻模型（R_total = R_series + R_dyn）

```text
R_dyn = R_DYNAMIC_BASE_MOHM(50mΩ)
      + (Vbatt <= 1900mV ? 300Ω 固定
         : min( 5x10^7 / (Vbatt - 1900mV), 250Ω ))
R_series = NVM 可校准（DIRECT 默认 360Ω；BATT 默认 360Ω + 2x25Ω）
```

### 11.4 五重安全限制（battery_get_safe_brt，取最小值）

| 限制 | 依据 | 说明 |
|---|---|---|
| limit_i_led | 峰值电流 <= i_max_ua(2.8mA) | 防止 LED 过流 |
| limit_v_drop | 压降后电压 >= WALL_MIN_V_BATT_MV(2400mV) | 电池电压“墙”，保底亮度 30 |
| limit_i_brt | 总放电电流 <= BATT_MAX_DISCHARGE_UA(4mA) | 限制电池总放电 |
| limit_p_avg | 总功率 <= BATT_MAX_DISCHARGE_UW(9mW) | 限制电池总功耗 |
| limit_v_derate | 电压 >=3300mV 无降额；线性降至 2400mV 时保底 30 | 电压线性降额 |

压降模型：v_drop_peak = i_peak x R_dyn x 30%（导通等效），v_drop_avg = i_peak x brt x R_dyn（平均）。
最终输出 safe_brt = min(req_brt, 各限制值)；所有中间量（g_safe_brt_out、g_limit_*、g_dyn_r_mohm、g_est_i_peak_ua）实时镜像到调试信箱，可在 RMRDebugger 中观察是哪一重限制在起作用。

### 11.5 档位自适应（FEATURE_ADAPTIVE_GEAR_LIMIT）

- 升档时若目标档 brt <= max_brt（安全上限）则正常升档
- 目标档超限但差值 <= SNAP_THRESHOLD_BRT(50) 也正常升档
- 明显越限 -> 仍升档但置 g_is_overshot（调试器可读，用于识别“电压不够高”）
- 降档时若当前档已越限 -> 连续回退到安全档

## 12. ALS 自动感光（算法细节）

### 12.1 曲线

```text
brt = ALS_SQRT_FACTOR(5) x sqrt(lux_count / 100)     （lux_count 为 OPT3001 结果寄存器计数）
     x (1 + 偏移%)                                    （5 段：+/-50/30/0%）
下限 = als_min_brt(30) ｜ 低照度上限 600 ｜ 高照度上限 800 ｜ 总上限 1000
```

分界：lux_count <= 1,000,000 用低照度上限 600，更高用 800。

### 12.2 平滑与限速（FEATURE_ALS_SMOOTHING）

- 指数移动平均（1/8 权重）
- 上升限速分档：低亮度每 tick +2、中亮度 +5、其他 +20；下降限速 -20
- 轮询周期：普通版 120ms，ECO 版 1s

### 12.3 故障处理

- 连续 3 次读取失败 -> SYS_ALS_ERR：LED 以 1.5s 周期闪烁（亮 600ms）提示
- 10s 后自恢复：关闭 ALS 切回手动模式并落盘
- 连续 3 次“故障->自恢复”后锁定 ALS（拒绝从手动切回 ALS，避免传感器永久损坏时的闪烁循环；当前在 ALS 时仍可切回手动）

## 13. 电源管理与保护（技术细节）

### 13.1 运行功耗控制

- LED 恒流驱动，电流由档位决定（0-2.8mA）
- ADC/VREF：普通版每 100ms 采样（ECO 版 500ms，采样前后开关电源域）
- ECO 版：主循环 WFI 睡眠替代 24MHz 忙等；OFF/FLASH 态 SYSOSC 降到 4MHz（GPTIMER14 同步重配，tick 恒为 1ms）；PWM 亮度不变时不重算不写寄存器；OFF 态 OPT3001 shutdown（0.4uA）

### 13.2 关机与深睡（STANDBY0）

- 双键 1.5s 熄灯 + 松开确认 -> SYS_OFF -> STANDBY0 深睡
- 深睡准备：WWDT 周期先拉伸再重启（约 8192s，防止 500ms 看门狗深睡复位）；IOMUX WCOMP 匹配低电平（按下即异步唤醒）+ GPIO 边沿中断双保险；受控 __disable_irq()/WFI
- 唤醒后：恢复 500ms 看门狗、禁用唤醒源、重新测压
- FLAG_SWD_IN_OFF_STATE(bit6)：置位则 OFF 态跳过深睡保持 SWD 可连（DBG 版出厂默认置位；ECO/DBGL 出厂默认清零）

### 13.3 无操作超时

- 40 分钟无操作 -> 调暗到 DIM_LEVEL(5)
- 再 10 分钟无操作 -> 自动关机
- 按键任意事件/调暗后按键 -> 立即恢复并清零计时

### 13.4 低压保护（LVP）

| 阈值 | 去抖 | 动作 |
|---|---|---|
| < lvp_crit(2300mV) | 连续 5 次 | SYS_LVP_CRIT：LED 每 2s 闪 50ms、亮度降 1/4 警示 |
| < lvp_ext(2100mV) | 连续 5 次 | 直接关机并保存配置 |
| < 2000mV（快速掉电） | 单次即触发 | 瞬间断 PWM + 立即保存 -> SHUTDOWN（DBG/DBGL 版不 SHUTDOWN，仅存配置保 SWD） |

- 开机测压门控：battery_startup_check() 必须测得电压 > lvp_ext + 100mV 才允许开机
- SYS_LVP_CRIT 回升自动恢复：电压 >= lvp_crit + 100mV 回 SYS_RUN

### 13.5 冷启动判定（AUTO_POWER_ON）

仅冷启动（RSTCAUSE = POR/BOR/SHUTDOWN 退出，或 SRAM g_por_magic 兜底）才执行自动开机；WWDT/SYSRST/调试复位一律保持关机——保证“1.5s 熄灯后不会被看门狗复位点亮”。

## 14. 配置记忆（NVM）

### 14.1 存储布局

- 记录大小固定 64 字节（编译期 _Static_assert），尾部 4 字节 FNV1a-32 CRC
- 存储区：扇区 A（0x3800）/ 扇区 B（0x3C00），各 1KB = 16 槽，双扇区轮转
- 加载：扫描全部槽位，取 CRC 合法且 seq_id 最大者；坏槽标记跳过
- 保存：槽位轮转 + 3 槽位尝试；写后回读校验 + 擦写耗时补偿；失败 3 次放弃本次（保留 RAM 影子与 dirty，后续重试最多 5 次）
- 后台 30s 自动保存（仅 RUN 态）；关机/LVP/掉电路径强制保存

### 14.2 可配置项（NVM 字段）

| 字段 | 默认值 | 说明 |
|---|---|---|
| params | lvl=4, ALS=0, offs=2 | 档位 0-8 ｜ ALS 使能 ｜ 偏移索引 0-4 |
| features | 8 位标志 | 运行时特性开关（受编译期 mask 过滤） |
| r_base | 50 mΩ | 动态内阻基数 |
| r_series | 360000 / 410000 mΩ | 串联限流电阻（电池版含 2x25Ω 内阻，可校准） |
| v_led_fw | 2200 mV | LED 正向压降 |
| i_max_ua | 2800 uA | LED 最大电流 |
| batt_p_uw | 9000 uW | 电池最大放电功率 |
| als_min_brt | 30 | ALS 最低亮度 |
| lvp_crit | 2300 mV | 低压临界 |
| lvp_ext | 2100 mV | 低压极值（关机） |
| als_sqrt_factor | 5 | ALS 曲线系数（0=用默认，NVM 1-20） |
| als_cap_low_x100 / als_cap_high_x100 | 6 / 8 | ALS 低/高照度亮度上限（0=用默认） |
| default_level | 4 | 出厂档位 |
| seq_id | — | 序列号（磨损均衡） |

### 14.3 恢复出厂

- 烧录后首次上电可选清空存储区（DEV_CLEAR_NVM_ON_POR=1）
- 调试器指令 5：恢复出厂 + 立即保存
- 出厂默认值宏在 app_config.h [0] 段，可编译期修改

## 15. 调试接口（RMRDebugger / 调试信箱 / IPC）

### 15.1 调试信箱（g_test_box，SWD 直接读 RAM）

- 授权：magic=0x54455354 + host_version 匹配；授权丢失 -> 复位；正常退出 -> SYS_FLASH_MODE
- 实时监视（每 tick 刷新）：电压（原始/滤波）、估算电流/功率/硬件功率、动态内阻、亮度/PWM、五重限制值、ALS 原始/滤波/传感器状态/错误计数、档位/偏移/模式、NVM 状态、复位原因、无操作秒数等
- 系统命令：2=复位 ｜ 3=写配置（mask 过滤）｜ 4=保存 ｜ 5=恢复出厂+保存 ｜ 6=开机（测压）｜ 7=关机
- 注入：模拟按键（+/-）、ALS 注入（开关+lux）、LED 注入（1=PWM 直驱 2=无限制亮度 3=受限亮度）、拦截物理按键
- 实时诊断：TEST 态每 tick 刷新计算数据（battery_get_safe_brt 全链路）

### 15.2 RMRDebugger（Qt 6）

- XDS110/DAPLink 自动扫描（OpenOCD SWD，5kHz-4MHz）
- 实时遥测：电压/电流/功率/内阻/档位/亮度/PWM/ALS/NVM 全字段 + 三张图表（10s 滚动窗口、Y 轴自适应）
- 一键烧录：擦除+编程+校验+复位；连接失败自动清理残留 OpenOCD 进程
- 测试模式：解锁/读配置/写配置/保存/恢复出厂/开关机/软复位
- 虚拟按键与真实按键语义一致；状态与操作合并显示
- Power-Z KM003C 电压电流计接入（HID，200ms 轮询，10s 滑动窗口平均）
- 隐藏 IPC：127.0.0.1:7345，JSON 行协议（ping/state/scan/setfw/flash/unlock/syscmd/cmd/write/read/poll/speed/key/power/led/als）
